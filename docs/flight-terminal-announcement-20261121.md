使用者要求登入頁維持現況；本次未變更登入頁、資料庫、更新頻率或天氣排版。

- 看板抵達播報加入來源已提供的桃園第一／第二航廈；未知或缺漏值不猜測。
- 班號逐字發音，保留數字零，例如 CI702 → C、I、七、零、二。
- 新增純函式及合成單元測試，沒有正式 API 請求或業務資料異動。
- 使用者接續確認取消通知：新鮮來源確認取消後保存 cancelledAt／最小航班快照於原 R2 追蹤，不刪追蹤、不增加 Supabase 輪詢。來源移除航班後仍能顯示此次事件；來源明確恢復且非陳舊時解除取消狀態。
- 取消卡片紅框、獨立取消播報；播畢三分鐘的紅框從頂部中央逆時針逐漸消失，最後卡片移除。幾何路徑以本機動畫更新，不發網路請求。沿用瀏覽器開啟聲音要求；播放失敗不開始倒數。
- 取消事件與抵達使用不同的本機防重播鍵，跨重新整理保留完成時間。超過十五分鐘未播的舊事件不補播，避免電視久離線後播過期警報。
- 追蹤區依預計時間（無則表訂）限制八小時內；更晚的原始追蹤保留，到範圍內下一次五秒名單更新自動顯示。缺少時間也沒有確認事件時不顯示。
- 已執行班號／航廈／時間邊界單元測試、R2 合成來源與權限測試、瀏覽器假時鐘的取消播報一次／九小時進八小時／半圈紅框／三分鐘隱藏及原輪播回歸。語音／新聞播放器使用模擬；實體電視聲音仍需現場確認。
