# 2026-11-18 手機報班、頭像與共用檢查更新

已按使用者指示更新原 Cloudflare＋雲端 Supabase 正式站。前端版本 `27d17b59-234b-4b5c-bcd3-d51db2b6895a`，相關資產改用 `20261118-1`，避免舊版報班檔案因不可變快取而持續顯示。

## 手機頭像與報班

- 原本人員權限管理中的 17 張員工頭像沒有被頁首新頭像資料來源讀取。頁首現在同時讀取自己的個人頭像與原本人員資料，優先使用個人設定，不複製或覆寫資料庫。頁首圖片立即載入；非同步取得頭像只更新頁首，不重新建立整頁而打斷報班。
- 司機報班取消重複月份標題，重設為「返回／上月、月份、下月／重新整理」同列。返回按鈕在載入或失敗時仍可使用；同一頁工作階段返回再進入，可保留未送出的休假選擇。
- 後台月份設定新增「條件限休」，可設定多組起日、迄日及每位司機最多可休天數，最多 20 組。同時落在重疊區間的日期須符合全部條件；0 天可限制整段不能休。
- 區間限額為硬性限制，前端阻擋超額選取，後端送出時再次檢查。原本每月超過排定天數仍可送督導審核的規則保留。每份報班保存當時的區間條件；新的設定若與已送出資料衝突會拒絕儲存，不改寫既有報班。舊版客戶端未送區間欄位時，保留原條件，不會清空。

## 司機車輛檢查

- 司機只看「待檢查／待審核／已通過」小型頁籤和檢查卡片，不再顯示批次、搜尋或大型統計。後台完整篩選保留。
- 直接點下方位置圖卡就開啟該位置的拍攝；不需捲回上方按相機。送出、通過或非自己領取的檢查不能更改照片。
- 發起清單按車輛合併目前駕駛。同車兩位司機共用一筆任務，任一人開始即可；開始後以資料庫列鎖領取，另一人可看進度，不能混拍或重複送出。後台通過後，兩人都可在「已通過」看到同一結果。
- 舊任務只在其他重複任務尚未開始時整併；若單一任務已有進度，保留該任務及其執行人。若同車多份任務都已有進度，不自動合併照片，保留供後台核對。被整併的空任務留存並標示取消、連到共用任務，附處理紀錄，不刪除任務或照片。
- 已領取任務若需要換人，後台可取消並重新發起；本版不自動把部分照片交給另一人續拍。
