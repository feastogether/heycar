# 2026-11-21 航班手機篩選修正

接續 `8f828bc`，依使用者 iPhone 截圖修正航班查詢篩選。只有前端修改，不部署 Supabase Functions、R2 Worker 或資料庫 migration。

- 原本絕對定位面板會超出內容高度，被手機主容器的 overflow 規則裁切；日期原生控制項亦有固有寬度問題。改為表單內正常文流的可收合面板，展開時頁面跟著長高，不覆蓋或被截斷。
- 桃園／高雄／TDX 改為同寬分段選項，保留原生 radio 語意及原 ID；日期與標籤同一行，加入 WebKit 日期內部值對齊與最小寬度限制。
- 返回、篩選、班號、查詢與重新整理仍維持單排。篩選按鈕維護 aria-expanded／aria-controls，送出查詢後自動收起，但所選來源與日期仍提交。
- 移除查詢下方靜態提示文字及初始「請輸入班號」空白框。實際查詢的進行中、無結果或失敗狀態仍保留，不捏造航班資料。
- 仍只依司機輸入的班號查詢，開啟／改動篩選不自動拉全量；原十分鐘快取不變。

驗證：`test-flight-filter-ui.cjs` 使用完整本機司機入口，在 Microsoft Edge 與 WebKit 27.2 引擎、320／390／430／768／1440px 檢查日期及面板邊界、日期下緣的 elementFromPoint 命中（確保沒有被祖先裁切）、機場切換、日期提交、收合及十分鐘快取。另通過 `test-dispatch.cjs --ui` 原派趟／航班與車商權限測試。WebKit 為桌面測試引擎，不代表已在實體 iPhone 上測試。
