# 後台介面規範

共用樣式：`assets/admin-ui.css`，限 `.admin-shell`／`.admin-workspace`。司機端仍用 `assets/driver-ui.css`。

- 標題與主要操作同一個 `.section-head`，操作包在 `.actions` 靠右。不要讓兩顆新增／匯出按鈕各占一列。
- 一般操作最小高 38px、字級 13px、行高 20px、圓角 9px、間隔 8px；圖示按鈕保留 aria-label。主動作一顆，其餘沿用 ghost／soft，危險操作用 danger 並確認。
- 篩選集中在標題下，同一排搜尋、下拉與查詢；允許窄螢幕合理換列。輸入與下拉高 38px，搜尋可伸縮，select 不無條件 width:100%。不以絕對定位拼版。
- 一般資料編輯視窗 920px 上限，下線流程 960px；手機保留邊距。header／footer 固定在框內，只有內容捲動，錯誤與儲存狀態在 footer；不要讓浮動聊天鈕蓋住操作。
- 確認優先在同一視窗內完成，不疊第二個原生 dialog。儲存期間鎖定連點及 ESC 關閉，保留失敗草稿；異動使用 revision／request_id，不能只靠 disabled 防重複。
- checkbox／radio 明訂尺寸，不能繼承一般文字輸入寬度。表格格子、照片角度選擇與班表密度可用專屬尺寸，不套一般按鈕來撐高每列。
- 手機 320／390／768px、桌面1440px驗證溢出、按鈕對齊、內容捲動、固定操作與鍵盤可達；Edge及WebKit。大型表格允許單一橫向區域，不建立第二個頁內垂直捲軸。
- 新功能遵守上述元件結構；舊專屬介面保留其必要資料密度，不為統一而刪掉操作或資訊。
