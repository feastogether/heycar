# 重新整理保留功能頁

原因：restoreSession 已呼叫 restoreViewState 還原後台頁面，下一行卻又用 initialAdminView 或 home 覆寫，導致一般後台 F5 固定回首頁。

修正：既有登入恢復時，以明確桌面啟動目標、已還原功能頁、預設首頁的順序決定頁面。新的登入流程仍沿用原本首頁規則。首頁資料先讀取的流程及各功能權限驗證不變。

每個分頁以 sessionStorage 保存自己的位置，保留 localStorage 的舊格式回復能力；加上角色／帳號識別避免切換人員後沿用他人位置。位置只存頁面與既有篩選欄位，不複製 Token、資料表內容或表單草稿。登出及清除登入時一併移除分頁位置。派趟日期仍依原規則回到台北當日。

Edge／WebKit 真實重新整理測試涵蓋後台車輛管理、司機班表、訂餐、兩個分頁獨立、司機報班、車商車庫、桌面指定功能優先及登出清除記憶。測試使用隔離合成預覽，未在正式送出業務表單。
