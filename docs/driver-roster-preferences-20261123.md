# 司機班表：排序、區域與記憶顯示

## 完成行為

- 「班表」更名「司機班表」，沿用 driverRoster view、driverReporting 權限及獨立頁，不更換既有休假／班別資料來源。
- 左側姓名旁支援原生向上／向下拖曳，也有上移／下移按鈕供手機或鍵盤操作。僅改顯示順序，不改司機 ID、車輛指派或派趟順序。篩選時移動仍保留未顯示的人員。
- 駕駛管理的 region 欄位改為下拉選單：北部、中部、南部、花東、其他。新增／變更區域的 API 同樣驗證五個值；原有自由文字區域可在舊客戶端不變動地送回，單獨文件／備註修改不因此被拒絕或改區域。不批次推測、轉換舊資料；編輯未知舊值時，顯示原值並要求選標準值。班表將未設定／非標準舊區域納入「其他」篩選，這只是顯示分類，沒有寫回資料庫。
- 班表加入區域篩選、整個月／週次／日期區間。週次按週日～週六劃分，月初／月底可能為不足七天的一週；日期區間限當月。使用 UTC 計算純日期週幾，避免瀏覽器時區影響；隱藏日期按 Asia/Taipei 的今日判定。
- 可勾選隱藏今天以前的日期，今天仍保留。過去月份若全部隱藏，保留工具列及可恢復的空狀態。剩餘日期自動填滿可用寬度，較少欄位時放大排程文字。左側三欄保持固定，手機在表格內橫向捲動。
- 顯示月份、期間模式／週次／起迄日、區域、隱藏過去及司機排序，存於 `heycar-driver-roster-v1:<identity>` 的 localStorage。依管理帳號隔離，重開頁面仍保留；**僅目前瀏覽器，沒有跨裝置或跨員工同步**。不保存登入 Token、照片、備註、整批人員資料或休假內容；僅排序所需 UUID 及顯示設定。損壞／不合法設定有安全預設值。
- 已完成保養／維修／調胎的格內排程自動反灰，保留位置、時間及完成勾號；不反灰整天而蓋掉休假／其他任務。沿用可見班表每分鐘小型 stamp 檢查，有變更才重載月資料，不增加全量輪詢。司機完成後約一分鐘內可自動顯示；午夜時隱藏過去設定也會更新。

## 架構與資料保護

本次無 migration、無資料庫回灌、無舊紀錄批次修改。排序及顯示設定是個人瀏覽器偏好。後端報班讀取僅對授權後台補上 `drivers.id,region` 小型投影，保留 driverReporting 授權；司機自己的報班回應不加入後台區域清單。新 `driver-regions.mjs` 共用區域規則，入口在角色／權限檢查後驗證新增／變更，其他局部更新維持相容。

預覽 adapter 同步地域資料，且 stamp 查詢前同步合成行事曆，讓真實完成 RPC 的自動反灰測試有效。所有新 UI 測試使用記憶體庫與自身資料夾，結束後精確清理；不連正式資料做表單測試。
