# 司機前台 UI 共用規範

適用 driver-workspace 與登入司機開啟的視窗；樣式入口 assets/driver-ui.css，body.is-driver-session 限制作用範圍。後台／車商／登入頁不套用。延續 HEYCAR 品牌，不另建另一套產品。

| 元件 | 規範 |
|---|---|
| 字型 | system-ui、Apple／Windows 系統字型、繁中字型；內文14px／1.5，輸入16px避免手機聚焦縮放 |
| 一般操作按鈕 | 最小高42px、圓角8px、13px半粗體、無陰影；圖文間6px |
| 返回／重新整理 | 工具列左側42×42方形返回，右側42×42圖示重新整理；中間分類／日期可橫向滑動，不另起一排 |
| 分類／日期箭頭 | 同高42px；箭頭可窄於一般文字按鈕，日期格依月曆用途保持等寬 |
| 色彩 | 主動作深灰藍、次動作白底細框、選取金色、危險操作保留警示色；不得僅靠顏色表示狀態 |
| 圖示 | 一般操作直接SVG 18px、線寬1.8；返回與重新整理42px點擊區。頭像保持圓形，拍攝方位圖不當作小圖示縮小 |
| 卡片 | 圓角12px、1px細框、16px內距；卡片間12px。高度依內容自適應，不硬截斷姓名／航班／提醒 |
| 欄位 | 42px最小高、圓角8px；checkbox/radio 18px、標籤可點，與隱藏分段選單例外分開 |
| 視窗 | 同一標題／本文／底部操作結構；距螢幕12px、最大寬720px，本文捲動、底部關閉／送出靠右 |
| 照片 | 4:3預覽、圓角12px、同規格外框；手機2欄、平板3欄、桌面車檢5欄。工單／輪胎使用文字位置，車檢保留對應方位圖 |
| 上傳 | 壓縮／傳送期間轉圈、狀態訊息及禁重複操作；照片草稿與輸入不得因重繪遺失；錯誤可重試 |
| 鍵盤／輔助 | focus-visible清晰金色外框，文字label／aria-label，狀態區role=status；手機觸控與鍵盤都能使用 |

新增功能優先使用現有 pageHeader／driver-toolbar 及共用 class，不再自行設定一套返回、刷新、卡片或輸入尺寸。日曆日期、車檢位置圖、個人頭像及整張卡片入口是不同語意元件，不強迫成一般按鈕。登入頁維持原設計。

驗證入口：scripts/test-driver-toolbar-ui.cjs（15功能×320/390/768/1440，Edge與OFFICE_WEBKIT=1）、test-workspace-refinements-ui.cjs（保養照片視窗）、test-vehicle-inspections-ui.cjs（10張照片／補拍／審核）、test-flight-filter-ui.cjs（手機日期可點擊性）。新模組與懶載入之後也要檢查共用樣式。
