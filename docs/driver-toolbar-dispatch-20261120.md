# 2026-11-20 司機前台共用工具列與派趟樣式

接續 `5805c62`。本次只修改前端與 R2 看板天氣顯示，不修改資料表、保養／報班／借還等業務規則，不回灌正式資料。

## 統一的司機操作

- 所有司機功能放在 `.driver-workspace` 範圍，以 `assets/driver-ui.css` 統一操作按鈕。返回為 42 × 42px、8px 圓角的方形「返回」，重新整理為同尺寸 ↻，均保留可讀的 aria-label／title。
- 頁面返回、重新整理、日期切換、分類與分頁放入單一 `.driver-toolbar`。過長分類只在頂列內橫向捲動，不能造成第二排工具列或整頁橫向溢出。每筆資料的拍照／確認／歸還等操作仍綁定該筆資料，不改其權限或流程。
- 報班保留月份選擇、禁休、超額審核、確認後鎖定；車檢保留十張照片、補拍與同車駕駛共用規則。只替換模組工具列及移動清單分類／分頁。
- HEY POINT 與用品租借的前台頁面移除重複大標題，禮品／兌換／明細與用品分類放在返回和重新整理之間；後台點數管理保留原工作區。
- 航班只留單列返回／篩選／班號／查詢／重新整理。機場和日期在「篩選」彈出區中；輸入指定班號後才查詢，原十分鐘快取及追蹤功能保留。相對航班 API URL 以 location.origin 解析，修正本機預覽的相對 URL 問題。
- 共同行事曆月份切換移到共用頂列；訊息已讀分類、司機幫手分類、公告分頁同樣移至頂列。

## 派趟

- 司機從首頁進入派趟中心，及載入舊的日期狀態時，都重設為台灣「今天」。日期左右箭頭與手動選日仍可正常查看其他日期，頁面刷新／資料重畫不重設正在查看的日期。
- 前後台共用 `dispatchOrderCard` 的 `dispatch-trip-card` 內容結構：時間、接送類型、來源、地區、航班／訂單號與車商／駕駛。保留查看明細、編輯、車商指派與更新提醒。
- 使用細邊框、白底、少量金色及普通字級層次，移除粗彩條、漸層、懸浮位移及大陰影。後台行動版既有編輯權限與刪除隱藏規則不變。

## 看板天氣

`cloudflare/board-briefing.js` 的天氣跑馬燈只顯示城市、溫度、今日降雨機率；來源與模式時間留在 metadata，不顯示於文字。舊的三十分鐘 R2 快取文字也先清理後輸出，不必等快取過期。日期驗證、延遲標記、跨日保護及台股日期／來源顯示保留。
