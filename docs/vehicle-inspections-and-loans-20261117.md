# 車輛檢查與租借修復（本機）

> 後續已獲使用者授權正式發布，詳見 [本次發布紀錄](production-release-20261117.md)。以下保留建立本機版本時的原始紀錄。

此更新僅在 `review/fleet-integration`，沒有推送、部署或修改正式資料庫。接續原本的本機預覽，入口 `http://127.0.0.1:4183/?review=admin`。

## 車輛檢查

- 後台新增獨立「車輛檢查」權限與選單。最高管理員可用；其他同仁可在權限管理開啟。
- 發起時依車商、車牌、目前駕駛勾選，設定標題、說明與期限。依車輛管理有效的駕駛紀錄比對，無有效紀錄才使用目前駕駛欄位；不接受任意車輛／司機組合。
- 司機首頁有檢查入口及待辦數，可逐一拍攝四邊、四角、由駕駛座向後的車內照片與儀表總里程，共十張，另填數字里程。照片縮至長邊 1600px、最多 2 MB；每張上傳成功立即保存，里程及說明可另存草稿。
- 十張齊全及里程完整才可送出。後台可放大審核、指定角度補拍、註明原因，或取消尚未完成任務。補拍保留先前照片及處理紀錄，送出後鎖定，通過後不可修改。
- 照片使用獨立私有 bucket、10 分鐘簽名網址。列表不下載照片；詳細頁才簽名。先前照片只載入最近 50 張，完整版本仍保存在資料庫及儲存空間。
- 所有寫入經受限 RPC；指定司機只能操作本人任務。版本檢查、防止重複批次與照片，以及回應遺失後重試不刪除已保存檔案。檢查不更新車輛、駕駛、履歷或原有文件。
- 這版使用站內待辦，沒有新增 LINE、簡訊或瀏覽器推播。實機相機操作需在實際手機再驗收；自動測試使用有效圖片模擬拍攝輸入。

## 租借修復

- 原本最高管理員被前端條件排除，無法登記還車；其他同仁卻會看到別人的還車按鈕。改為本人可還自己的借用，最高管理員可代登記，其他人仍可查看使用資訊。
- 核准 → 登記還車 → 確認結案改為獨立 RPC，檢查角色、擁有人、最新版本、合法狀態與還車時間，並在同一交易寫入操作者與時間紀錄。重試不重複處理。
- 核准時以車輛為單位鎖定，防止同時核准重疊借用；已超過預計還車時間但尚未結案的借用仍視為占用。
- 一般編輯不能改寫流程狀態、借用人或還車／核准／結案時間，且有版本條件防止覆蓋。
- 借車時段衝突檢查移入儲存的 try/finally，失敗後會恢復按鈕；還車不再經過新借車的時段檢查。
- 上方改成精簡標題與登記按鈕；使用中車輛圖示、使用者、借用時間及篩選保留在可展開區域。
- 本機恢復原先備份的 60 筆租借供閱覽，來源是既有私有備份快照，並非即時同步正式站；沒有覆蓋車輛或駕駛資料。
- 原本精簡的本機車輛資料未包含駕駛紀錄、目前駕駛及使用人名稱。依車輛 ID 從既有備份補入缺少的欄位，已有欄位一律保留，不寫回正式站。檢查名單排除已離職者，不沿用報班僅限指定車商／狀態的規則。
