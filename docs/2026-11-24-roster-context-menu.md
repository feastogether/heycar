# 司機班表滑鼠與鍵盤操作修正

日期：2026-11-24（Asia/Taipei），基準 04aaa60；前端資產 20261124-5。純前端，未變更 SQL／API／R2，也沒有提交正式業務表單。

## 最終操作

- 每日格子一般左鍵仍開原備註／顏色表單，移除表單內的出車／休假按鈕。保養／調胎標籤仍開原排程。
- 每日格子右鍵只顯示「出車」「休假」。已休假以勾號／aria-checked 標示，再選「休假」取消當日休假；取消不會把當日改為出車，也不動其他日期。出車沿用寫入出車備註並移除該日休假。
- 姓名左鍵恢復編輯該司機整月報班日曆；姓名右鍵只顯示「編輯位置」。不再用雙擊姓名改位置。姓名黑色、置中、提高字重，區域／位置小字保留。
- 滑鼠左鍵拖曳選擇矩形格子，不開編輯框；Ctrl+C 複製，點目的格後 Ctrl+V 直接貼上。複製後第一個目的格點擊作為貼上選取，其餘一般左鍵編輯維持。Ctrl／Meta＋點擊、原範圍選取／Shift／方向鍵操作亦可選格。貼上後保留選取範圍與焦點，能再次 Ctrl+C／Ctrl+V。
- 原工具列貼上仍有預覽；真正鍵盤貼上不再要求多格確認。遇保養衝突仍須確認，原200格上限、單月份、版本檢查與整批回滾保留。複製只涵蓋備註／顏色／休假，不複製實際保養排程或車輛指派。

## 相容性與保護

原生 copy／paste 事件讀寫系統剪貼簿，不以測試程式注入 ClipboardEvent 代替鍵盤驗證。部分 WebKit 環境會把同頁原生 paste 的文字交付為空，僅在本人剛於同頁複製、未離開焦點、兩分鐘內且為可信任 paste 事件時，可用該次已選取資料補回；換帳號、離開視窗／分頁、在其他欄位複製都不沿用此備援，避免把外部空白剪貼簿當舊資料。仍保留 Excel 引號／多行 TSV 解析。

右鍵選單支援 Escape／上下鍵、點外側關閉、實際捲動／縮放或離開頁面時清理；忽略排隊的舊 scroll／resize 事件，避免窄螢幕剛定位就閃退。文檔監聽器用 AbortController、MutationObserver 隨選單關閉清除。快捷與直接貼上防止同時重送，沿用現有交易 RPC／revision／audit，原審核狀態不變。
