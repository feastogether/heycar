發布查核：資料庫增量、API、儲存 Worker 與前端已發布；已執行正式資料保留與唯讀功能驗證。使用原有 Cloudflare、R2、Supabase，不重建或回灌正式資料庫。

## 本次功能

- 手機跑馬燈縮小；司機檢查移除中間重複指引，保留下方位置拍照格。
- 檢查批次可新增／取消車輛；已通過任務不可取消。臨時抽檢可指定司機、選擇所需角度並填寫地點，未指定角度沿用十張。
- 檢查批次 ZIP 包含明細及各版本照片，依車牌、批號、司機建資料夾。下載後另行確認才永久清理照片；保留任務、照片 metadata 與操作紀錄。下載失敗不進行清理，過期 manifest 不可清理新照片。
- 聊天修正帳號切換殘留／群組失效；新訊息排序、頭像及手機輸入列延續既有設計。瀏覽器通知由使用者主動開啟；網站需保持開啟，作業系統決定通知位置，未實作網站關閉後的 Web Push。
- 待回覆意見顯示側欄數量。保養司機選擇提供搜尋、車商篩選及跑趟中名單，預設亞菲得；明確改派才更換原司機。
- 共同行事曆每日明細改為資訊卡；保養完整表格保留清楚欄寬與單一頁面垂直捲動；報表設定新增車商篩選。
- 司機完成保養需輸入里程並拍四顆輪胎及工單五張照片；後台通知操作有「照片」。完成資訊回到通知／排程／預測，仍須人工建立真實工單，不自動寫車輛履歷。一般群發提醒維持原本完成邏輯。
- HEY POINT：授權人員發點需原因；不可重複發放；帳本、商品庫存、兌換及取消退款採交易處理。司機點系統頭像查看點數，不開放司機改頭像。
- 安椅管理：安全座椅／增高墊編號、啟停、借還紀錄；司機借出與歸還皆須拍照，伺服器記錄時間，同一用品僅一筆有效借用。
- 我的車輛使用後台車型圖片；儲存空間列入車檢、保養及用品照片。作業照片由原功能管理，禁止一般檔案刪除破壞紀錄。
- 衛星犬位置卡片改為車輛圖示／速度與狀態。憑證只在 Supabase Secrets；不把密碼放進原始碼。
- 移除連結管理入口與前後台操作；保留歷史 `driver_links` 資料，API 寫入回覆停用。

## Egress 的具體調整

使用者提供帳單為 7.961／5 GB；容量與函式次數未接近上限。唯讀檢查時有 7,575 筆派趟，原始 JSON 約 16 MB，這是單次資料量，不能據此認定帳單來源占比。

1. 移除後台首頁自動預抓完整工作區。派趟依選定日期查詢；司機更新只取當日／所選日期，不再每次重載所有功能。
2. 聊天改為增量訊息，聯絡人最多每五分鐘重載；舊訊息依 ID 合併並保留讀取更新，查詢索引同步補齊。
3. 新車檢／保養／用品照片在瀏覽器壓縮後直傳私人 R2，Supabase 只處理上傳許可、簽收憑證及業務 metadata。舊照片留在原 Supabase bucket，以混合儲存 adapter 讀取；不批次搬檔或替換既有附件。
4. 上傳許可及簽收分開、HMAC 驗證、綁定本人／用途／位置／請求 ID；不可拿上傳許可偽裝完成憑證。檔案不可覆蓋，重試只能使用相同內容。
5. 電視航班資料先由 Cloudflare 抓桃園公開來源，以既有 R2 共用五分鐘快取；來源直連若回 522，改用既有 flights 服務的精簡 gzip 備援，仍僅讀桃園抵達資料。備援保留原來源時間；必要時使用交通部 TDX 桃園資料並標明來源。電視每分鐘讀取小型看板；跑馬燈最多每五分鐘重讀 Supabase，配對後不重查 Supabase 登入資料。2026-11-20 實測備援約 15,951 bytes 壓縮資料；這是單次回應，不是帳單節費保證。
6. 華視影片由電視直接連 YouTube，完全不代理或存進 Supabase。影片仍使用電視所在地的網路流量。

已用 Egress 不會因刪檔重設；舊照片下載仍可能產生 Supabase 流量。R2 的儲存／操作有各自用量，不把「R2 對外流量不計費」說成所有操作免費。

## 電視航班／新聞看板

- 入口：`/flight-board`。後台「跑馬燈號」有入口，進入「配對設定」產生 30 天唯讀電視連結；可停用該連結。需要最高管理員或對應跑馬燈／調度等權限。
- 配對 token 放 URL fragment，頁面讀取後移除並只存電視瀏覽器；R2 僅保存 hash，影片 Referer 不含配對資訊。不要把此連結貼到公開地方；不在電視輸入管理員登入碼。
- 司機原航班查詢後，可追蹤今天／明天的桃園抵達班機。司機姓名取伺服器登入資料，不信任前端姓名；取消追蹤限本人。
- 顯示追蹤航班、即將抵達、航廈、更新狀態及原系統啟用的跑馬燈。只根據機場明確「已到／抵達機坪」等判定落地，不能以預計時間已過推測落地。
- 首次使用需按「啟用降落廣播」，電視瀏覽器需支援 Web Audio、中文 Speech Synthesis。原創三音提示後播報航班與司機，完成後三分鐘移除；同一電視重整不重複播報已播事件，陳舊抵達不補播。
- 新聞來源：依使用者確認，從受外站播放限制的台視改為「華視新聞 CH52」官方直播。2026-11-20 核對 `https://news.cts.com.tw/live` 及 YouTube `wM0g8EoUZ_E`，實際於正式網域的嵌入環境驗證影片 readyState=4、未暫停且播放時間前進。未修改或偽造 Referer，也未繞過來源限制。新直播 ID 可使用儲存 Worker 的非機密變數 `CTS_LIVE_VIDEO_ID` 更新；頁面保留官方入口與重試。
- 新聞預設靜音，允許現場開啟新聞聲音。落地廣播期間暫時靜音，結束恢復原設定。保留 YouTube 正常播放器控制，不代理串流、不繞過嵌入或播放限制。
- 主畫面可全螢幕；未配對、來源延遲、過期連結、播放器失敗有明確提示，不偽造航班或落地狀態。

## 程式與設定

- `flight-board.html`、`assets/flight-board.{js,css}`：獨立電視 UI／廣播。
- `assets/flight-board-news.js`：官方 YouTube iframe、聲音與廣播避讓。

- `assets/driver-benefits.{js,css}`、`driver-benefits.mjs`：點數、用品、五張保養照片。
- migrations `20261120010000`、`20261120020000`、`20261120030000`：檢查擴充、點數用品／照片與完成里程、聊天增量索引。只部署這三個已演練增量。
- 公開前端設定 `DIRECT_MEDIA_UPLOAD`：正式啟用前，需先設定並部署儲存 Worker 與 data-api；合成預覽預設關閉以使用本機檔案。
