- 台北、桃園、新竹、台中、台南、高雄：Open-Meteo 一次多地查詢。顯示目前模式溫度與「今日」最大降雨機率，含來源與模式時間，三十分鐘 R2 共用快取。

## 永久連結取回

原本只存 SHA-256 雜湊，建立後原始 Token 無法逆推。現在使用既有 `MEDIA_SIGNING_SECRET` 經用途分離推導 AES-GCM 金鑰，連結 Token 加密保存於私人 R2 access 記錄，AAD 綁定連結 ID。沒有新增、輸出或旋轉金鑰。

- `pair_list` 不回傳 Token。只有通過原有 `boardManagement` 權限驗證的 `pair_link` 才可解密取回，提供「複製連結」「顯示連結」。重新開啟管理頁仍可使用。
- 舊連結在原電視以有效 Token 重新讀取 snapshot／pulse 時補存加密值，採 etag 防覆蓋，保留原記錄及名稱；原網址與電視使用權不變。
- 從未重新連線的舊雜湊無法逆推。管理頁明確提示先到原電視重新整理；若未曾使用該網址，可產生新連結。不可假裝取回或默默停用原電視。
- 原撤銷流程保留；停用後讀取與取回均失效。日後若旋轉 MEDIA_SIGNING_SECRET，必須規劃已加密連結的金鑰遷移，不能直接重設。
