# 班表、司機選取與保養工單更新

## 行為與介面

- 選單「行控中心」下新增獨立 **班表**，沿用 driverReporting 權限。原司機報班保留清單及人數日曆，不再將班表混在同頁。班表使用全寬工作區，顯示整個月份、所有符合資格的司機，不做司機分頁；固定左側司機、目前車牌及月份班別。司機過多時仍可捲動，手機保留橫向閱讀，不將文字壓成無法辨識的尺寸。
- 班別由後台自由填寫，例如 04-17，每月每人一筆，最長 40 字；獨立於人事或派趟資料。每日格雙擊可編輯任務備註。保養／維修顯示「保」、調胎顯示「調」，後接保養廠前兩字及時間；完整廠名保留於 title，排程完成保留勾號。休假核准綠色、待審紅色。班表依舊每分鐘只檢查小型 stamp，有變更才重讀資料。
- 司機報班清單以姓名及目前綁定車牌顯示，不再重複車商名稱；審核與編輯按鈕不折行。每位司機始終有編輯日曆入口，包括未報班者。後台可在未開放月份安排休假；若月份尚不存在，只建立關閉的月份設定，不會開放司機填報。新建後台休假為已同意，既有申請仍維持原審核狀態；均保留 audit 與 revision，衝突拒絕覆蓋。
- 意見反饋的前後台改為一致的卡片層級：類別／標題／內容、回覆區、狀態及操作；長文換行，手機不橫向溢出，保留原回覆／結案功能。
- 交付／返還車檢的車牌、司機可輸入後即時顯示符合的結果，支援姓名／手機、鍵盤選擇；車牌仍可直接填未建檔的車牌，司機必須從資料庫清單選取。結果每次最多 30 筆，繼續輸入可縮小範圍，選取不改正式車輛駕駛。
- 保養完成仍必填里程與四顆輪胎照片；工單可拍照或明確勾選「尚未有工單」。前者五張、後者四張，均驗證位置、照片歸屬與未使用狀態。後台照片檢視顯示「尚未有工單 · 待補登」。原預測→排程→司機完成→待登工單流程保持，不自動建立車輛履歷。

## 離職司機規則

新選擇排除狀態「已離職」及舊別名「離職」：一般司機選單、搜尋、用車駕駛紀錄新指派、保養及匯入對應、派趟／車商指派、費用、點數、車檢目錄。駕駛管理與歷史資料仍保留這些人員，不刪資料、不順便停用帳號。

後端除選單過濾外，九種業務資料表新增指派保護 trigger：vehicles、calendar_events、maintenance_notifications、personal_messages、payment_notices、dispatch_orders、vehicle_loans、vehicle_inspection_tasks、driver_roster_shifts。只擋新增／變更的司機關聯，保留未變動的歷史關聯，因此仍可處理舊案件或歸還原借車。車輛目前駕駛、新增開放中的駕駛歷程、車檢共用司機也檢查。點數發放另在 RPC 前檢查，帳戶清單保留歷史姓名但以 selectable=false 排除新選取；取消兌換與退點維持可用，不把歷史資產鎖死。

舊案件編輯時，原離職司機以隱藏的已選歷史選項保留，不放回可選清單；不可因過濾清單而將 driver_id 清空。費用目錄保留全部人員的姓名及狀態供歷史顯示，新增選單才過濾，避免舊費用變成「未指定」。

## 資料結構、權限與部署

正式已套用的新 migration，不可再修改：

- `20261123030000_roster_workspace.sql`：driver_roster_shifts／audit、CAS 班別保存、可建立未報班休假的 admin_set、唯讀目前車牌投影與擴充班表排程。
- `20261123040000_driver_selection_and_missing_work_order.sql`：指派保護、篩選／歷史顯示用目錄、maintenance_notifications.work_order_pending、四／五張照片完成 RPC、同步更新舊完成流程的照片防呆 trigger。

API 新增 `save_driver_roster_shift`、`admin_set_driver_leave`，必須在 index.ts 分派表及 reportingActions 同步存在。班表延用 driverReporting 權限，司機端禁止呼叫管理動作。新表 RLS、RPC 限 service_role；data-api 仍使用既有自訂 Session 授權。沒有新增環境變數或外部服務。

發布前重新備份 70 張 public 表、800 筆 Storage objects metadata，取得當下函式／constraint 定義，在 PGlite 還原完整備份並演練。正式套用採 repeatable-read 交易，原有 70 表欄位加 Storage objects／buckets 共 72 組資料內容前後比對一致才提交。沒有舊庫回灌、業務刪除或駕駛／附件覆蓋。實體照片未另行下載，metadata 備份不能視為實體照片備份。私人資料在忽略的 `.fleet-preview/release-20261123-roster/`。

正式前端 `01e539d4-37af-4d93-925b-85ec441cdee5`；data-api **96**，verify_jwt=false 沿用自訂授權。前端九個變更檔案實際下載雜湊與測試來源相同，最終班表 CSS 再核對；R2／航班 API 未更動。JS 資產多為 20261123-4，app／driver-benefits 為 20261123-6，班表 CSS 20261123-5。
