# Hey!car 管理列印站

這是給 Windows 印表機工作站使用的全螢幕 Electron 入口。啟動後可選擇「車輛租借」或「寄信管理」；寄信管理沿用網站現有的一般標籤與貼紙標籤列印功能。

2026-10-25 起停用共用代碼 `0000` 與自動登入；請使用具備對應功能權限的有效後台帳號登入。原有 EXE 載入線上系統，這項登入調整不需重裝 EXE。

在 `desktop` 目錄執行 `npm install`，開發測試使用 `npm start`，產生 Windows 安裝程式使用 `npm run dist`。目前列印會開啟 Windows 列印視窗，可選擇已安裝的印表機與紙張。
